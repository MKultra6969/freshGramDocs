# DESIGN.md: сайт документации плагинов freshGram

Этот файл — источник правды для визуала. Новые стили и компоненты берут значения отсюда. Если нужного токена нет, сначала добавь его сюда, потом в CSS.

## 1. Назначение

Справочник и руководство для разработчиков плагинов бета-версии freshGram. Читатели работают с именами API, полями манифеста, кодом и таблицами лимитов. Главное: быстро найти нужное место, прочитать точный текст и скопировать пример без потерь. Оформление служит чтению и поиску, а не демонстрации.

## 2. Принципы

1. Текст и код первичны. Фон, рамки и цвет нужны для иерархии, а не для украшения.
2. Один заметный ход на сайте: колесо логотипа (`freshgram-wheel.svg`) над заголовком главной страницы. Всё остальное строго и спокойно.
3. Статус всегда показывается значком и текстом, никогда одним цветом.
4. Все интерактивные элементы имеют видимый фокус и область нажатия не меньше 44×44 CSS px.
5. Цвет берётся только из токенов. Ни одного hex-значения в компонентах.
6. Зелёный бренд — основа палитры, но текст и мелкие элементы используют тёмный оттенок, который проходит контраст.

## 4. Типографика

- Текст интерфейса: `ui-sans-serif, system-ui, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif`. Кириллица — системными шрифтами, без внешних шрифтов.
- Код: `ui-monospace, "Cascadia Code", "JetBrains Mono", Consolas, "Liberation Mono", monospace`.
- Веса: только 400, 600, 700.
- Шкала (rem, база 16px):
  - тело страницы: 1rem, line-height 1.65;
  - подписи, мета, пункты меню, поиск: 0.9375rem (15px) и 0.875rem (14px); ниже 14px текст не ставим;
  - h1: `clamp(1.875rem, 1.4rem + 1.6vw, 2.5rem)`, line-height 1.2, вес 700, letter-spacing -0.02em;
  - h2: 1.5rem, line-height 1.3, вес 700, отступ сверху 48px, снизу 16px, с нижней линией `--border`;
  - h3: 1.2rem, line-height 1.35, вес 600, отступ сверху 32px;
  - inline-код: 0.9em, но не меньше 0.875rem (14px), фон `--surface-muted`, радиус 4px, padding 0.1em 0.35em;
  - блок кода: 0.875rem, line-height 1.6.
- Измерение текста: колонка прозы не шире 72ch.
- Заглавные буквы не используем, кроме аббревиатур.

## 5. Сетка и плотность

- Базовый шаг отступов: 4, 8, 12, 16, 24, 32, 48, 64 px. Других значений в компонентах нет.
- Шапка: высота 56px, sticky, фон `--surface` с границей `--border` внизу.
- Боковое меню: 272px, sticky, прокручивается внутри себя.
- Контент: колонка прозы до 72ch; блоки кода и таблицы могут быть шире колонки прозы, до полной ширины контента.
- Оглавление: колонка 200px, справа от контента.
- Поля: 16px на телефоне, 40px на широком экране.

Брейкпоинты:
- до 899px: боковое меню в drawer, открывается кнопкой меню;
- 900–1199px: боковое меню и контент;
- от 1200px: боковое меню, контент и оглавление.

## 6. Поверхности и рамки

- Радиусы: 6px для кнопок, полей, пунктов меню; 10px для блоков кода, callout и карточек пагинации; 999px для бейджей статуса. Никаких радиусов больше 10px на контейнерах.
- Рамки: 1px, цвет `--border` для разделителей, `--border-strong` для полей и кнопок.
- Тени: только у выпадающих панелей (поиск, drawer): `0 12px 32px rgba(13, 20, 16, 0.14)` в светлой теме и `0 12px 32px rgba(0, 0, 0, 0.5)` в тёмной.
- Вложенные карточки запрещены. Карточка есть только у пагинации внизу страницы.
- Градиенты запрещены.

## 7. Компоненты

Иконки: библиотека `lucide-react`, размер 18px, толщина штриха 1.75. Декоративные иконки получают `aria-hidden="true"`. Кнопки только с иконкой получают `aria-label`.

Соответствие иконок:
- разделы меню: Начало — `Rocket`; Разработка — `Package`; Концепции — `BookOpen`; Возможности — `Puzzle`; Справочник — `Braces`; Примеры — `FileCode`; Статус — `Activity`; Поддержка — `LifeBuoy`; Внутренности — `Cpu`;
- статусы: стабильно — `CircleCheck`; экспериментально — `FlaskConical`; WIP — `Wrench`;
- callout: NOTE — `Info`; TIP — `Lightbulb`; WARNING — `TriangleAlert`; CAUTION — `OctagonAlert`;
- интерфейс: поиск — `Search`; меню — `Menu`; закрыть — `X`; тема — `SunMedium`, `MoonStar`, `Monitor` (для системной); копировать — `Copy`, после копирования `Check`; внешняя ссылка — `ExternalLink`; хлебная крошка — `ChevronRight`; пагинация — `ChevronLeft`, `ChevronRight`.

Компоненты:
- **Пункт меню.** Высота не меньше 44px (`--hit-size`), текст 15px. Иконок у пунктов страниц нет: иконка слева только у заголовка раздела. Активный пункт: фон `--accent-soft`, текст `--accent`, полоска 3px цвета `--accent-fill` слева, высотой на весь пункт, со скруглением 2px. Заголовок раздела: иконка слева (по соответствию выше) и название 14px, вес 600, цвет `--text-muted`.
- **Кнопки.** Видимая часть 40px (`--control-size`), область нажатия 44×44 px за счёт `--hit-extend`. Наведение: фон `--surface-muted`. Фокус: `outline: 2px solid var(--accent)`, `outline-offset: 2px`, без отключения обводки.
- **Ссылки в тексте.** Цвет `--accent`, подчёркивание с `text-underline-offset: 3px`, толщина 1px. Стрелок на ссылках нет, кроме внешних: в конце внешней ссылки иконка `ExternalLink` 14px.
- **Поле поиска.** Высота 44px (`--hit-size`), иконка `Search` слева, рамка `--border-strong`, фокус как у кнопок. Подсказка «/» видна только от 1200px: фон `--surface`, рамка `--border`, текст `--text-muted`. Результаты: панель `--surface`, рамка `--border`, тень выпадающей панели, строки не ниже 44px, заголовок 15px/600, раздел 14px `--text-muted`.
- **Бейдж статуса.** Высота 24px, иконка 14px и текст 14px, вес 600, цвет и фон по статусу из раздела 3.
- **Callout.** Фон `--surface` с цветной полосой слева 3px цвета статуса, заголовок с иконкой и названием (Примечание, Совет, Внимание, Осторожно), текст 16px. Цвет полосы и иконки задаётся токеном типа: NOTE — `--info`, TIP — `--success`, WARNING — `--warning`, CAUTION — `--danger`.
- **Блок кода.** Шапка 44px (`--hit-size`): слева язык в моноширинном 14px `--text-muted`, справа кнопка «Копировать» высотой 40px (иконка и подпись на широком экране, только иконка на узком). Тело: фон `--code-bg`, рамка `--code-border`, отступы 16px, прокрутка по горизонтали внутри блока.
- **Таблицы.** Ширина 100%, заголовок на `--surface-muted`, строки с линией `--border`, отступы ячеек 8px 12px. Таблица оборачивается в контейнер с горизонтальной прокруткой.
- **Пагинация.** Две карточки «Назад» и «Далее» рядом (на узком экране друг под другом). Подпись 14px `--text-muted`, название 16px/600 `--text`. Наведение: рамка `--border-strong`.
- **Оглавление.** Строка видимая 36px, область нажатия расширяется до 44px через `::after`. Активный раздел отмечается цветом `--accent` и полоской `--stripe-width`. Переходы цвета 120ms, как у пунктов меню.
- **Хлебные крошки.** Ссылки в крошках имеют область нажатия 44px по высоте, как у пунктов меню; видимый текст 14px.
- **Баннер беты.** Полоса над страницей: фон `--warning-bg`, текст `--text`, иконка `TriangleAlert` цвета `--warning`, текст «Документация описывает бета-версию: API может меняться».

## 8. Движение

- Цвет и фон: 120ms, `ease-out`.
- Drawer: выезд 200ms, `cubic-bezier(0.2, 0.7, 0.2, 1)`, затемнение фона 200ms.
- Анимации по прокрутке отсутствуют.
- `prefers-reduced-motion: reduce`: все переходы и анимации отключены, drawer появляется без выезда.

## 9. Адаптивность

- Телефон (320–599px): шапка в две строки: вверху меню, логотип и тема; под ней поиск на всю ширину. Боковое меню в drawer. Пагинация в столбец. Блоки кода и таблицы прокручиваются внутри себя, страница не прокручивается по горизонтали.
- Узкая шапка: название бренда «freshGram · плагины» на телефоне не обрезается многоточием. Суффикс «· плагины» (`.brand-suffix`) скрывается ниже 360px, на экранах 360px и шире показывается полностью. Обрезка названия бренда недопустима.
- Планшет (600–1199px): шапка в одну строку, поиск занимает свободное место. Боковое меню видно от 900px.
- Широкий экран (от 1200px): трёхколоночная композиция с оглавлением. Подсказка «/» в поиске.
- Заголовки переносятся по словам. Длинные идентификаторы в прозе (`overflow-wrap: anywhere` только для инлайн-кода).

## 10. Страница главной

Колесо логотипа (`freshgram-wheel.svg`) — единственный логотип сайта. Оно показывается в шапке (28px) и над заголовком главной страницы и страницы ошибки (96px). Версия одна для обеих тем: у колеса собственный зелёный фон. Других декоративных изображений нет.

## 10a. Версия документации

Версия документации совпадает с версией клиента freshGram. Источник правды — файл клиента `Telegram/build/version` (поля `AppVersionStr` и `BetaChannel`). В проекте значение лежит в `src/version.ts` (`DOCS_VERSION`, `DOCS_CHANNEL`, `DOCS_VERSION_LABEL`); обновляется командой `npm run sync-version` при заданной переменной `FRESHGRAM_SRC` (путь к корню исходников клиента), см. README.

Где показывается:
- подвал бокового меню: строка «Документация для freshGram 7.5.10 beta», шрифт 14px, цвет `--text-muted`;
- главная страница: та же строка в заголовке страницы, под бейджем статуса. Над шапкой и под баннером беты строки версии нет: она выглядела бы частью шапки.

Версия не выводится в шапке, чтобы не занимать место на телефоне.

## 10b. Ссылки и формат для ИИ-агентов

Ссылки на репозитории (в интерфейсе, на русском):
- Шапка: иконка GitHub-знака в кнопке 44px, `aria-label` «freshGram на GitHub: официальный репозиторий», ведёт на https://github.com/Snowy-Fluffy/freshGram. Видна на всех ширинах. Иконка GitHub — встроенный SVG-компонент в `src/components/icons.tsx` (в lucide-react бренд-иконок нет).
- Подвал бокового меню, два строчных блока: «Официальный репозиторий freshGram» (https://github.com/Snowy-Fluffy/freshGram) и «Создатель документации: MKultra6969» (https://github.com/MKultra6969). Текст 14px, цвет `--accent`, иконка GitHub 14px с `aria-hidden`. Внешние ссылки открываются в новой вкладке с `rel="noopener noreferrer"`.

Кнопки для ИИ-агентов в заголовке каждой страницы, под описанием, ряд из двух кнопок 40px (область нажатия 44px):
- «Скопировать для ИИ»: иконка `Copy`, после копирования `Check` и подпись «Скопировано». Копирует Markdown страницы: заголовок, описание и тело, без frontmatter. Фолбэк через `execCommand`, если Clipboard API недоступен. `aria-live="polite"` для статуса.
- «Скачать .md»: иконка `Download`, скачивает тот же текст файлом `<slug>.md`.
На узком экране (до 599px) у кнопок остаётся только иконка, `aria-label` сохраняется.

Экспорт всей документации для агентов: в подвале бокового меню две ссылки, `llms.txt` (индекс со ссылками на Markdown каждой страницы) и `llms-full.txt` (весь текст одним файлом). Генерируются скриптом `scripts/build-llms.mjs` перед сборкой (`prebuild`). Файлы в `public/` попадают в `dist/` и в Docker-образ. Формат `llms.txt`: заголовок H1, цитата-описание, разделы с ссылками на `md/<slug>.md`.

## 11. Запрещено

- Фиолетовые и сине-фиолетовые градиенты, любые градиенты.
- Цвет как единственный признак статуса или ошибки.
- Hex-значения и магические числа в компонентах: только токены и шаг 4px.
- Текст мельче 14px и серый на сером вместо иерархии.
- Стрелки после каждой ссылки, нумерация-маркеры в заголовках, эмодзи вместо иконок.
- Вложенные карточки, радиусы больше 10px на контейнерах, тени кроме выпадающих панелей.
- Анимации по прокрутке, неоновый зелёный на светлом фоне.
- Отключение фокуса (`outline: none`) без замены.
- Горизонтальная прокрутка страницы на любой ширине от 320px.
